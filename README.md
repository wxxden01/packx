# PACKX
## Description du projet:
Packx est un gestionnaire de paquet pour distribution Linux, il n'a pas pour but de concurrancer `apt`, `pacman` ou nimporte quel autre gestionnaires de paquets!

La philosophie est de faire quelque chose de simple et facile à implanter sur des pétites distro en construction (étape BLFS).

# Compilation

``` bash
make
cd build/
```
